Aiven for PostgreSQL

Free: Free: 1 VM, 1 CPU, 1 GB RAM, 1 GB storage; no cloud or region choice.

  • Only entry prices are printed; larger plans sit behind "View 7 plans". Rows use each plan's entry configuration.
  • All networking cost is included per the page. Dynamic disk sizing costs extra on Startup and up (rate not printed), so extra storage is not modeled.
  • Business adds high availability (2 VMs); Premium adds a second standby (3 VMs).

Heroku Postgres

Free: No free plan. Essential 0 is $5/mo (shared, 1 GB storage).

  • Classic plans bundle a storage cap; there is no per-GB add-on, so a bigger disk means a bigger plan.
  • Essential 0/1/2 ($5/$9/$20, 1/10/32 GB) run on shared resources with no stated RAM, so they are not in RAM-based comparisons.
  • Premium plans add high availability. Advanced tier pricing was not printed as text.
